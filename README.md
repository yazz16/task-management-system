# Task Management System (Java)

A console-based task manager built for my Data Structures & Algorithms coursework,
using **custom-built data structures** instead of Java's built-in collections.

## Data structures implemented
| Structure | Used for |
|---|---|
| Linked List (`TaskLinkedList`, `Node`) | Storing and managing all tasks |
| Queue (`TaskQueue`) | Processing tasks in order (FIFO) |
| Stack (`TaskStack`) | Tracking recent actions / history (LIFO) |

## Features
- Add, update, delete and view tasks
- Process tasks in order using a queue
- Track history using a stack

## Run it
Open the `TaskManagementSystemN 3` folder in IntelliJ / Eclipse and run `src/TMS/Main.java`.

## What I learned
Implementing core data structures from scratch and choosing the right structure for each operation.
